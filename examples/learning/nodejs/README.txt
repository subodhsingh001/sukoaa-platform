Sukoaa Node.js HTTP starter (Node 22+; tested with Node 24).
No npm packages are needed. Run npm test, then npm start.
Open http://localhost:3000/health or /api/products?inStock=true.
POST /api/echo accepts JSON up to 8,000 bytes. Nothing is persisted.
This is a teaching API without authentication, not a production service.
The optional Sukoaa browser Node lab uses WebContainers; provider browser
support, network access and applicable licence terms still apply.
