BROWSER LABS
/labs/postgresql — real PGlite 0.5.15 PostgreSQL WebAssembly engine.
Run SELECT/WITH/EXPLAIN queries against fictional products. JSONB and window
functions are supported and tested. Read-only transaction, 200 displayed
rows, 12,000-character input and five-second query timeout. First startup
has a 30-second deadline. Stop resets the disposable in-memory engine.
This is not a remote PostgreSQL server and is separate from SQLite/Supabase.
It does not include every server extension or native PostgreSQL feature.

/labs/tailwindcss — real Tailwind browser 4.2.1 utility compilation.
Edit static HTML and utility classes. Refresh creates a sandboxed preview;
exercise checks inspect computed styles. Scripts, external resources and
active elements are removed. Preview network access is blocked. Use the
CLI starter to generate production CSS; the browser engine is for practice.

/labs/nodejs — optional, experimental WebContainer Node environment.
A dependency-free HTTP server runs in the browser VM. No npm install step.
The API request check is a real HTTP request from a short-lived Node process
inside that same VM. This avoids preview-proxy CORS restrictions. The editor
and terminal have size limits; startup stops waiting after 30 seconds.
Applicable WebContainer provider terms, browser support, connectivity and
site-owner configuration still apply. This route is deliberately noindex.
It uses the existing NEXT_PUBLIC_WEBCONTAINER_MODE and public API-key settings
when configured. No provider subscription or licence has been purchased.

No heavy learning runtime downloads until Run or Refresh is chosen.
On low-memory devices, use one heavy browser lab at a time or use a local
starter. The website never executes students' server code on its web host.

LOCAL STARTERS
Download from the track page or /api/learning/starters/<technology>.
The same source is in examples/learning/<technology>/ in this project.
- FastAPI: Python virtual environment, pinned requirements, five TestClient
  checks, Uvicorn command, /docs, validated query/body parameters and errors.
- Node.js: no dependencies, real HTTP tests, /health, filtered products and
  a bounded JSON echo request. Node 22+; tested with Node 24.
- PostgreSQL: Docker Compose with PostgreSQL 17, loopback port 5433, schema,
  fictional records, JSONB and window queries. Demo credentials are local only.
- Tailwind CSS: pinned CLI 4.2.1 starter with responsive HTML and a static
  production stylesheet build.
- PHP: a small request handler, local development router and five logic
  checks. Requires PHP 8.3+. No Composer dependency for this starter.
- Laravel: a minimal Laravel 13 API project, Composer dependencies, routes,
  validation and four framework test methods. Requires PHP 8.3+ extensions
  and Composer 2. Run the included tests locally before relying on it.
All sample writes are fictional and non-persistent. These are teaching
projects, without production authentication or deployment hardening.

DATABASE / DEPLOYMENT
No new database migration for this release. If cloud Play & Learn progress
was already configured in v0.17.0, keep the same play_profiles table/policies.
Guest progress and the new lab drafts work locally. For a first cloud setup,
use the existing PLAY-CLOUD-PROGRESS-SQL.txt, then test account isolation.

Use Node 24 for this platform. Keep .env.local private. Run:
  npm ci --include=dev
  npm test
  npm run build
Then review, commit and push your GitHub deployment branch to update Vercel.
The ChatGPT preview publication does not update your personal GitHub repo or
www.sukoaa.com automatically. No extra domain is required for these modules.
