DEPLOY
npm run typecheck && npm run build, push, let Vercel deploy. Production env must be:
APP_ORIGIN=https://www.sukoaa.com  SITE_URL=https://www.sukoaa.com  SITE_INDEXING_ENABLED=true
Then: npm run seo:check -- https://www.sukoaa.com
Then Search Console (see docs/18-GOOGLE-SEO-SETUP.txt): verify the domain, submit
https://www.sukoaa.com/sitemap.xml, Request indexing for /, /tools, /practice, /tools/python,
/tools/json and the new /practice/* hubs.

WHAT CODE CANNOT DO (the real ranking levers)
- No one can guarantee page 1. "online python compiler" is dominated by large sites.
- Realistic first targets: the brand query "sukoaa", then long-tail pages: JSON validator,
  SQLite playground, "python dictionary exercises", "javascript reduce practice", etc.
- Backlinks: Show HN, Product Hunt, dev.to/Hashnode write-ups, GitHub README links, relevant
  subreddits/communities. This is usually the biggest missing factor for a new domain.
- Keep adding genuinely useful exercises (aim for 50+) and a short explainer on each tool page.
- Measure: Search Console Performance, PageSpeed Insights (mobile) for /, /tools/python, /practice.
- Not done here: per-page social images, sitemap lastmod (only add if dates are accurate).
