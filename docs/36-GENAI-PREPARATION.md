Route: /learn/gen-ai. Added 22 November 2026.

## Delivered scope

40 original lessons covering the supplied concept list, with 10 modules, 40 worked exercises, 40 core interview questions and 40 answered follow-ups. Each topic includes a simple explanation, an analogy, engineering detail, an explicit numeric or behavioral example, a misconception correction, four guided stages and primary background references.

The course includes five timed mock-round formats, four runnable Python coding tasks with example/boundary checks and four capstone project briefs with evidence checklists. These are teaching formats, not alleged employer questions or a guaranteed hiring process.

## Practice features

Foundation, Engineering and Interview views support different depths of relevant experience. The visual walkthrough advances only when selected or after an explicit Play action; it stops at the final stage. Reduced-motion preferences disable decorative transitions.

Engineering labs calculate sampling probabilities, context allocation, lexical/rank-fusion retrieval, bounded agent transitions, independent-step reliability, judge confusion metrics, action permission gates, token charges, model/KV memory and LoRA parameter counts. Semantic example scores are explicitly fixed; the course does not pretend to run a hidden embedding model. Pricing and overhead are editable assumptions, not live provider quotes.

Completion markers, bookmarks and lesson notes are stored locally with bounded validated backup/merge. Mock scratchpad notes have a separate local draft and download. No new account, model API, database table, key or third-party client dependency was added.

New links appear in the homepage learning resources, Learn navigation and interview-prep page. Existing question banks remain intact. New pages join the existing sitemap path list; existing URLs and SEO metadata were preserved.

## Corrected claims from the references

Agent memory retention and deletion are explicit, not automatic permanence. Self-reflection does not guarantee correctness. Temperature is not a truth score. Context overflow is application/provider-specific. The 36% chain result assumes independent equal probabilities. Cache savings, token counts and GPU fit are not universal. KV heads and GB/GiB units are explicit. Model judges and guardrails require calibrated evaluation.

## Limits

Guided visuals are conceptual animations, not live model telemetry. Labs are deterministic learning demonstrations and permission examples are not a complete production security system. Local records need backup before browser data is cleared. Project briefs do not silently install or run a model, and calculations do not replace benchmarks. Existing compilers and account/API implementations were verified byte-for-byte against the prior delivered source.
