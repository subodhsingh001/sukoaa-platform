SUKOAA v0.15.5 - BACKGROUND ENVIRONMENT PREPARATION

WHAT CHANGED
Angular and Next.js dependency setup starts automatically for the selected project after the editor is ready, the page has fully loaded, and the visitor pauses typing for two seconds. Where supported, the browser must also give an idle callback.

This does not download both frameworks from the homepage. React Fast, Python, JavaScript and other quick playgrounds keep their existing behavior.

WHAT THE VISITOR SEES
A small status in the studio toolbar shows installation progress and then "Environment ready - press Run". The editor remains usable. Details opens the terminal. Stop cancels an active preparation.

Preparation only writes source files and installs npm dependencies with install scripts disabled. It does not start the development server, execute the visitor's application, or create a preview. Press Run to compile and start the app. Clicking Run while setup is active joins that installation and synchronizes the newest source edits.

On returning to a prepared-but-never-run tool, the application still waits for Run. Previously started sessions continue to resume as in v0.15.4.

RESOURCE GUARDS
Automatic work waits while the page is hidden or offline. Data saver, reported 2G/3G connections, reported device memory of 4 GB or less, or two CPU cores or fewer keep preparation manual. Unknown device hints do not prevent setup. Run can still be used manually.

Queued work is cancelled when navigating away or clicking Run/Stop. Once an installation has started, normal tool navigation lets it finish in the retained session; Stop cancels it. This is scheduling, not a guarantee of zero CPU, memory, or network usage during installation.

Cloud projects require manual Run. Imports and new starters may still require additional setup. A change to package.json/lockfile is checked again on Run. Browser refresh or closing the tab still loses the in-memory runtime. Initial server compilation can still take time, especially for large Angular projects. No instant startup promise.

DEPLOY ON VERCEL
1. Replace the project source in your existing GitHub checkout with this complete archive. Preserve your .env.local and Git metadata. Never upload node_modules or .next output.
2. Run npm ci --include=dev
3. Run npm run typecheck
4. Run npm test
5. Run npm run build
6. Commit and push to your existing GitHub branch. Vercel will deploy if that branch is connected.
7. Open /studio?framework=angular or /studio?framework=nextjs. Wait for the editor, then watch the preparation status before pressing Run.

No extra service, API key, Supabase migration, Redis change, or new account is required for this update. AI remains disabled.
