SUKOAA - MOBILE DESIGN FIXES AND COPY CLEAN-UP (on top of v0.25.0 + SEO update)

Checked in a phone-sized Chromium (411px wide, 2x) against the same pages as the screenshots.

BUGS FIXED
1. Blank green Run button (/workspace on phones).
   Cause: app/globals.css, @media(max-width:900px): ".bench-controls>div>button>span{display:none}" hid every
   direct span in the toolbar buttons. The Run button's play icon and its "Run" label are both direct spans.
   Fix: a more specific rule keeps them visible for .run-button.
2. Line numbers out of line with the code (Monaco editor, /workspace, /labs/*, /studio).
   Cause: the fallback textarea editor styles ".line-numbers" (20px padding, 12px/1.9 font). Monaco uses the same
   class name for its own gutter numbers, so those rules leaked in and pushed every number about 18px off.
   Fix: a Monaco-only reset in app/globals.css. Measured: first number and first code line now share the same top.
3. "Save local" and "Share link" overlapping: .save-action buttons had no gap. Added one.
4. Phone toolbar clutter.
   /workspace: Run is now first and full width, then Layout/Options, then Save/Share.
   /studio: Run project first, "Reset widths" hidden on phones (panel widths do not apply when stacked),
   and the refresh/expand icons in the preview bar are centred instead of floating above the label.
