RUN LOCALLY
1. Extract the full source ZIP into a clean folder.
2. Open sukoaa-platform in a terminal.
3. npm ci --include=dev
4. npm run dev
5. Open http://localhost:3000/interview-prep
No AI key, database migration, Redis or account is needed for Interview Prep.
The earlier Gemini wording feature retains its independent local-only setup.
To put these changes on www.sukoaa.com, update your GitHub project and let
Vercel build the new source. This ZIP does not itself update GitHub or Vercel.

HOW TO USE IT FOR A GENAI TRANSITION
Select GenAI -> Foundations even if you have many years of frontend work.
Experience labels describe practice in this subject, not total years employed.
Start with tokens, embeddings and prompting. Continue to RAG, Python async,
structured outputs and evaluation. Work on the practical task, write an answer,
then reveal the reference. Mark only the rubric points you actually covered.
Save a self-review and a concrete improvement note. Revisit weak questions.
Move to Applied Practice for the screenshot RAG questions. Move to System
Design / Leadership for judge reliability, statistical uncertainty and controls.
Use the worksheet to explain a personal project honestly. Do not invent
production usage, results or ownership. Reference answers are examples, not
scripts to memorize or official employer answer keys.

QUESTION COUNTS AND EXPERIENCE
The 60 questions are an initial focused library, not a complete hiring syllabus.
Ten at each level let us cover the subject with explanations rather than pad
it with superficial duplicates. There is no universal employer-required count.
Editorial expansion targets per track, cumulatively:
- Foundations: 50-75 well-covered questions plus practical exercises.
- Independent delivery: 80-120 covering implementation, debugging and tests.
- Senior ownership: 120-180 covering architecture, incidents and trade-offs.
These are future Sukoaa planning targets, not extra questions already shipped.
Senior frontend roles also require role-specific coding, algorithms, browser,
architecture and leadership practice beyond this starting set. Use the target
job description and recruiter guidance to fill gaps.

LOCAL DATA AND PRIVACY
Answers, bookmarks, confidence, latest five review summaries per question,
project worksheet and active mock state stay in browser localStorage.
No interview answer is sent to AI or a server by this feature.
Cloud sync, automatic grading, voice recording and an AI interviewer are not
included. Confidence and coverage are explicitly self-reported.
Export a backup before clearing browser data or moving to another device.
Backups contain your writing in plain text. Restore validates the file before
asking to replace interview progress. Other Sukoaa feature data is untouched.
Previous answer texts are not versioned; only current drafts and five recent
review summaries are retained. Export snapshots if you need answer history.
If another tab changes progress, autosaving pauses rather than silently
replacing it. Export the current work and reload the saved version.
Single-question timers reset on reload. Mock deadlines and pause state persist;
a running timer continues while the page is closed and never deletes answers.
